# Salaah Task Manager

A simple, responsive task manager built with HTML, CSS and vanilla JavaScript for the Salaah recruitment (Technical Operations, Round 1).

**Live demo:** <add your deployed link here>

## Features
- Add, complete and delete tasks
- Filter by All / Pending / Completed
- Tasks saved in Local Storage (they survive a page refresh)
- Clear all completed tasks in one click
- Responsive from mobile to desktop, with keyboard focus and screen reader labels

## Run locally
Open `index.html` in a browser. No build step or dependencies.

## Tech
HTML5, CSS3, JavaScript (ES5-compatible), Local Storage API.
